# Ancrage — site web

Projet Next.js (App Router) + TypeScript. Design system repris des maquettes (accueil, opportunités, fiche acquisition, espace investisseur, back-office).

## Contenu de ce premier envoi

- Page d'accueil fonctionnelle (`app/page.tsx`)
- Design system global (`app/globals.css`)
- Structure de base prête à accueillir les pages suivantes

## Mise en ligne (voir explications complètes dans le chat)

1. Créer un dépôt sur GitHub et y déposer tous ces fichiers
2. Importer ce dépôt sur Vercel
3. Vercel installe les dépendances et déploie automatiquement

Aucune configuration serveur nécessaire pour cette première étape.
